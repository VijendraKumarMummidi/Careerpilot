## ✨ Features

* Resume ATS Analyzer
* Skill Gap Detection
* AI Roadmap Generator
* Mock Interview System
* Dashboard Analytics

---

## ⚙️ Setup

### 1. Clone

git clone https://github.com/YOUR_USERNAME/AICareerPilot.git
cd AICareerPilot

### 2. Install

chmod +x setup.sh
./setup.sh

### 3. Run

Backend:
cd backend && npm run dev

Frontend:
cd frontend && npm run dev
